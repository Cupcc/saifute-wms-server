    像编辑白板一样调整流程

    1. 拖动节点改变位置；从边缘圆点拖出连线。
    2. 双击节点 / 连线改字；选中后也可在右侧编辑。
    3. 点“连线”，再依次点起点和终点；Esc 取消。
    4. 选中连线拖动折点；Delete 删除，⌘/Ctrl Z 撤销。
    5. 拖动空白平移；滚轮缩放；“全图”查看全部。
    6. 点击“3D 场景”可从倾斜俯视角观看办公区与小人流转。
    7. 保存草稿：同浏览器、同文件位置下继续；不可代替备份。
    8. 下载当前 HTML：生成包含最新内容的独立离线编辑器。
    9. 导出 JSON：备份全部三个画布；导出 PNG / SVG：仅当前画布。

    离线文件不上传数据，不接入 WMS，不支持多人实时协同。浏览器隐私模式或清理缓存可能丢失草稿，请下载文件留存。
