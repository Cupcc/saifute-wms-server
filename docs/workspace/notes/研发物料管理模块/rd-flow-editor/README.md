# 研发物料流程 · 独立离线编辑器

交付文件：[研发物料流程编辑器.html](../研发物料流程编辑器.html)。将这一份 HTML 复制到任意文件夹，用桌面浏览器打开即可；无需安装 Node、WMS、服务器或联网。X6 2.18.1 的运行时、样式及 MIT 许可均内嵌在 HTML 内。

## 日常操作

- 拖动节点；双击节点/连线修改文字；右侧属性栏可修改负责人、说明、颜色、宽度和高度。
- 从节点边缘圆点拖出连线，或点击“连线”后依次选择起点、终点。选中连线可调整折点及两端连接。
- 新增步骤、判断框、说明卡；复制和删除节点；撤销/重做。删除节点会一并移除关联连线，可撤销恢复。
- 拖动空白平移、滚轮缩放；“全图”显示全部内容；“定位到步骤”以 100% 比例查看单个步骤。
- 三个画布预置采购与交接、项目库存与成本、角色职责；只有明确的业务规则被画为既定流程。

## 立体办公场景

后续美术与交互扩展请沿用：[场景风格 Prompt 与一致性规范](场景风格Prompt.md)（`SOFT-AXON-OFFICE-v1`）。

点击工具栏的「▦ 3D 场景」，进入倾斜俯视的开放式办公模型。六个空间包括研发办公区、需求复核台、采购办公室、研发物料区、主仓交接区、供应商收货区；桌子、电脑、货架、物料箱与人物均以 XYZ 几何投影绘制，带明暗和深度遮挡，无需网络、WebGL 或外部模型。

- 播放 / 暂停、下一步、重播；支持 0.5× / 1× / 2× 速度和 25°–65° 俯视角。
- 工位人物表示负责人；移动人物携带单据或物料演示交接，并不表示某位真实员工全程搬运。默认走首条常规连线，有多个出口时可在右侧选择异常或其他分支。
- 标题、负责人、说明和路线读取当前页面数据。没有后续连线时停止；遇到重复节点暂停，避免无限循环。无连线的职责页只供点击浏览，不虚构业务顺序。
- 点击右侧步骤会定位并暂停；点「返回编辑」或 Esc 返回流程图。场景隐藏或浏览器标签隐藏时不继续绘制；系统开启减少动态效果时不自动播放。
- 布局是预置业务的示意工位映射，不是实际办公室平面图，也不是家具搭建编辑器。已有节点仍用预置 ID 分配工位，新增 / 自定义节点默认放在研发办公区；不根据流程图拖动坐标重排房间。
- 场景不执行 WMS 操作，也不新增线上审批规则。播放位置、速度和镜头不写入草稿。下载 HTML 包含场景和最新流程数据；JSON 保持原格式，PNG / SVG 仍导出二维流程图。

## 保存与分享

| 操作 | 保存内容 | 下次如何编辑 |
| --- | --- | --- |
| 自动保存 / 保存草稿 | 全部画布，在当前浏览器本地 | 同浏览器、同文件位置打开，确认恢复草稿 |
| 下载当前 HTML | 全部画布和完整编辑器 | 打开下载的新 HTML，可复制给同事离线编辑 |
| 导出 JSON | 全部画布的可编辑数据 | 在编辑器中导入 JSON |
| PNG / SVG | 当前画布的展示图片 | 图片用于查看；继续编辑请用 HTML 或 JSON |

**保存草稿不会修改硬盘上的原 HTML。** 隐私模式、清理浏览器数据、换浏览器或移动文件可能导致草稿不可用。修改完成后请“下载当前 HTML”或“导出 JSON”留存。各副本独立编辑，不提供多人协同。

导入 JSON 会先验证格式、节点标识、连接关系和数据大小，再经确认替换所有画布；支持撤销。导入只接受本编辑器的版本化数据格式，不接受任意 X6 JSON、SVG 或第三方 HTML。恶意标签作为普通文字显示，不加载远程图片或脚本。

## 维护与重新打包（仅开发者需要）

此目录是独立小项目，不属于 WMS 构建或路由。不要在 `web/package.json` 中添加依赖。

```sh
cd docs/workspace/notes/rd-flow-editor
pnpm --ignore-workspace install --frozen-lockfile
node build.mjs
node --test model.test.mjs
```

- `model.js`：预置业务流程、严格导入格式、文本处理。
- `editor.js`：X6 图形交互、编辑、草稿、导出及可选浏览器原生工具接口。
- `scene-model.js`：独立、无副作用的流程演示状态与工位 / 通道映射。
- `scene.js`：Canvas 三维投影、人物 / 家具、深度绘制与播放控制。
- `shell.html` / `editor.css`：独立界面。
- `build.mjs`：将固定版本 X6、样式、模型和编辑逻辑内联为单文件 HTML；打包本身无需网络。
- `pnpm-lock.yaml`：独立依赖锁文件；`jsdom` 仅用于测试，不进入交付 HTML。

### 业务口径
